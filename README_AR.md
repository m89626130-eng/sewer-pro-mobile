# SEWER PRO 1.0.7 — تطبيق Android

هذه حزمة مشروع Android لتحويل برنامج SEWER PRO إلى تطبيق مستقل يظهر بأيقونة على الهاتف ويعمل دون إنترنت.

## ما الذي تتضمنه الحزمة؟
- تطبيق Android باسم **SEWER PRO** وأيقونة خاصة.
- واجهة البرنامج الحالية داخل التطبيق، وتعمل دون اتصال بالإنترنت.
- حفظ المشروع تلقائياً داخل بيانات التطبيق على الهاتف.
- فتح ملفات المشروع JSON من الهاتف.
- حفظ ملفات المشروع JSON وتقارير CSV باستخدام نافذة الحفظ في Android.
- طباعة التقرير أو حفظه PDF عبر خدمة الطباعة في Android.
- ملف GitHub Actions لبناء APK تلقائياً بعد رفع المشروع إلى مستودع GitHub.

## بناء APK عبر GitHub Actions
1. أنشئ مستودعاً جديداً في GitHub باسم `sewer-pro-mobile`.
2. فك ضغط هذه الحزمة على الكمبيوتر.
3. ارفع **كل محتويات المجلد** إلى جذر المستودع، مع مجلد `.github`.
4. افتح تبويب **Actions** في المستودع.
5. افتح سير العمل **Build SEWER PRO Android APK** وانتظر ظهور علامة النجاح الخضراء.
6. افتح عملية البناء الناجحة، ثم من قسم **Artifacts** نزّل `SEWER-PRO-Android-APK`.
7. فك ضغط ملف Artifact على الكمبيوتر أو الهاتف، ثم افتح `app-debug.apk` على هاتف Android وثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر.

## البناء من Android Studio
افتح هذا المجلد في Android Studio، ثم نفّذ Gradle Sync وبعدها Build > Build Bundle(s) / APK(s) > Build APK(s). الملف الناتج يكون في `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظات مهمة
- هذه حزمة مشروع Android جاهزة للبناء، وليست ملف APK مبنياً مسبقاً؛ بيئة العمل الحالية لا تحتوي على Android SDK/Gradle لإنتاج APK محلياً.
- بعد التثبيت تظهر أيقونة **SEWER PRO** على شاشة التطبيقات ويمكن إضافتها إلى الشاشة الرئيسية.
- التطبيق يعمل دون إنترنت لأن ملفات البرنامج مضمّنة داخله.
- الحسابات الهندسية ما زالت نسخة أولية؛ يجب مطابقة معادلات طبقات المنهول والردم والحفر مع مقطع التنفيذ المعتمد قبل استخدامها كقيم تنفيذية نهائية.
